What the call graph can't tell you

  • It reads names and runs nothing, so it shows what a function could call. Which branch runs depends on the input.
  • Calls into other packages, such as matrixStats::colMeans2, are not links here. Each function lists them under External calls.
  • The only dynamic calls in R/ are do.call sites: computeScores running a scorer (drawn), forLoop running its fun, and each scorer running transform.fun.
  • 13 internal functions have no path from any export: subsetData, subsetVector, subsetMatrix, getArgsInFunFormals, setVerbose, setPath, setLevel, logAll, logTrace, printLogLine, normaliseData, transformData, computeBcaCI.
