1Your data

Choose an expression matrix and a gene signature. You can drop new files here, or pick files already in the Sigshell data folder.

Expression matrix

Genes in rows, samples in columns. First row: sample names. First column: gene IDs. A .csv file, or tab-separated .tsv or .txt.

Gene signature

One gene ID per line, spelled as in the matrix. An optional weight can follow each gene after a tab or comma.

Files you add are copied into the data folder. Your originals are never changed.
